# LTC4020 Buck-Boost Battery Charger

## Overview

This project presents the design of a high-power buck-boost battery charger based on the LTC4020 controller.

## Features

- Input Voltage: 9–55 V
- Output Voltage: 12–14 V
- Charging Current: Up to 15 A

## Tools

- Altium Designer
- LTspice
