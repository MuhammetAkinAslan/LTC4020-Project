# LTC4020 Buck-Boost Battery Charger

## Overview

This project presents the design and simulation of a high-power buck-boost battery charger based on the LTC4020 controller. The system was developed for charging a 12 V lead-acid battery from a 28 V DC input while also supplying power to the connected load.

The project focuses on power-stage design, charging-voltage configuration, current-sense calculations, component selection, LTspice simulation, and PCB design considerations.

## Design Specifications

- Input voltage: 28 V DC
- Battery type: 12 V lead-acid battery
- Absorption charging voltage: 14.4 V
- Float charging voltage: 13.3 V
- Instant-on voltage: 12.25 V
- Battery charging current target: 2.5 A
- Maximum system current target: 15 A
- Buck-boost power conversion topology

## Design Process

The project included the following engineering activities:

- Analysis of the LTC4020 operating principle
- Battery charging-voltage configuration
- Current-sense resistor calculations
- Inductor and MOSFET selection
- Power-stage simulation in LTspice
- Current and voltage waveform analysis
- PCB schematic and layout development
- High-current routing and thermal design considerations

## Simulation

LTspice simulations were used to evaluate the electrical behavior of the charger, including:

- Battery charging current
- System output current
- Inductor current
- Input and output voltage behavior
- Switching waveforms
- Current-sense voltage

## Design Tools

- Altium Designer
